# SpinDepth3D 实时查看器

直接读取 STM32 测距 demo：115200、8N1、8×8、约 5 Hz。一个窗口同时显示距离数字/伪彩色和可旋转的彩色表面，便于观察物体的大致起伏与轮廓。串口帧格式兼容原固件；新固件改为 40 ms 积分以改善近距测量稳定性，已编译但尚未烧录，详见[固件说明](../002_Firmware/VL53L8CH_Demo/README.md)。清空测量区域并固定传感器后，点击“采集地面”可用 30 个完整帧建立逐区参考，完成后自动切换为相对起伏；取消“显示相对起伏”可切回原始距离。

## 本机启动

项目虚拟环境已创建在 `.venv`。当前检测并实测的 CH340 端口是 COM33；更换连接后以设备管理器中的端口为准。在 PowerShell 中执行：

```powershell
Set-Location 'D:\Github\SpinDepth_3D\002_Software'
& '.\.venv\Scripts\python.exe' main.py --port COM33
```

先关闭占用同一 COM 口的串口助手。窗口内拖动鼠标旋转三维视角，滚轮缩放。地面参考仅保存在当前运行期间；重启后需重新采集。关闭窗口会停止接收并释放串口；拔线后重新连接设备，再重新启动程序。

当前使用 Tkinter 单窗口和 Open3D 旧版 `Visualizer` 渲染，绕开本机 AMD 驱动上出错的 Filament 路径。Tkinter 随当前 Python 提供，无需新增 pip 依赖；渲染和界面更新都在主线程中进行。

## 新环境安装

使用 Python 3.12 x64。在本目录执行：

```powershell
py -3.12 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements.txt
```

无需激活虚拟环境。当前本机 `.venv` 使用应用附带的 Python 3.12.14 创建；如果该基础运行时迁移或被删除，应使用自己安装的 Python 3.12 重建 `.venv`。

## 数据与显示约定

- 仅发布收齐 D0～D7、S0～S7、N0～N7 的完整帧；每行 8 个值，目标数总和应与帧头一致。拆包、粘包、残帧、异常行和设备重启后均可重新同步。
- 距离已经是毫米，不重复缩放。测试范围限定在 1 米内：使用 `N > 0`、`S = 5 或 9` 且 `0 <= D <= 1000 mm` 的数据；无效或超距格显示 `--`，不生成三维点，不参与地面采集。原始距离保留，不截断数值；状态栏的 `Valid` 也按此范围计数。
- 保持固件数组顺序：第 0 行在最上方，第 0 列在最左侧。实物方向对应尚待实机确认，确认后只修改统一映射。
- 色标固定为 0～1000 mm，近处橙色、远处蓝色；灰色表示无效或超距。1 米上限只限制使用范围，不会增加传感器的 64 个采样区域或改变毫米输出步长。
- 地面采集对每个区域取有效样本中位数；30 帧中至少 24 次有效才建立该区域参考。参考固定到本次运行结束，失败重采不覆盖旧参考。相对值为“地面参考距离 - 当前距离”，靠近传感器为正、远离为负；色标为 0～200 mm 蓝到橙，范围外仅截断颜色。它是逐区距离差预览，不是精确垂直高度；少量地面正负抖动正常。
- 三维坐标为 `X = col - 3.5`、`Y = 3.5 - row`、`Z = -distance_mm / 100`。距离越近，点越高；X/Y 是区域索引，Z 每显示单位对应 100 mm。这是区域网格预览，不能用于测量物体长宽或解释为真实三维尺寸。
- 相邻有效测点连接为三角面，最多 98 个面；颜色、光照与网格边线帮助观察轮廓，测点以小方点保留。缺失区域不补值、不跨区连接，零散测点单独显示。原始距离和相对起伏共用这套显示方式；相对模式的 Z 为相对起伏 / 100。
- 表面只有 8×8 个测量区域。连接处的斜坡是直线近似，细小物体、锐利边缘及遮挡后的外形无法从这些数据恢复；建议先采集地面，再放入物体观察相对起伏。
- 仅使用最新完整帧，不积压显示队列。2 秒未收到完整帧或串口断开时，清空旧画面并提示状态；全无效帧是合法的空点云。
- 帧率按主机接收完整帧的时间估计。FRAME 为会回绕的传感器计数；不宣称采集时间、精确丢帧率或 CRC 校验结果。`Parse errors` 统计被丢弃的解析候选/异常行，不等同于丢失帧数。固件 `ERROR` 信息同时输出到启动终端。

## 检查

1 米范围修改后，22 项逻辑测试及真实窗口检查通过，包括 1000/1001 mm 边界、负距离、超距原始值保留，以及地面采集和相对显示统一使用范围。

无需硬件的自动测试：

```powershell
& '.\.venv\Scripts\python.exe' -m unittest discover -s tests -v
```

窗口冒烟检查无需开发板，使用测试文本帧打开真实窗口，检查彩色表面、旋转、缩放、地面采集、相对/原始模式、正负起伏、采集超时、断线和关闭清理，再自动关闭：

```powershell
& '.\.venv\Scripts\python.exe' tests\smoke_gui.py
```

测试窗口会在约 10～15 秒后自动关闭；终端出现 `GUI PASS` 表示正常完成，不是闪退。这只是开发检查，不是产品模拟模式，也不表示实机通过。界面中实际显示的三维图像写入忽略提交的 `artifacts/gui_depth_preview.png` 和 `artifacts/gui_surface_preview.png`；后者使用合成地面与中央凸起展示相对表面。

自动逻辑测试通过，覆盖逐区中位数、24/30 有效阈值、重复帧、缺失区、全无效帧、正负起伏、原始值兼容与三角面连接。检查确认三角面朝上、不跨越缺失行、顶点索引与有效测点对应。真实窗口检查通过：98 个彩色面、相对模式取景、空/孤立点时移除旧表面、30 帧地面采集、参考切换、正负起伏、2 秒与 15 秒超时、失败重采保留旧参考，以及原有渲染与串口断开检查。

原 Filament 界面在本地桌面也会发生 `wglMakeCurrent / Windows error 2000`，并在 AMD `atio6axx.dll` 内访问异常；不能归因于远程桌面。此前为解决闪退仅替换显示实现，未修改系统驱动或显示设置，依赖版本不变。

此前默认积分时间固件的 COM33 实机短时联调已通过：完整窗口运行约 10 秒，接收 53 个完整帧，约 5.0 Hz，解析错误为 0；真实点云已显示，关闭窗口后接收线程正常退出并释放串口。测试画面保存在忽略提交的 `artifacts/live_COM33.png`。该记录不代表新 40 ms 积分配置已通过实机验证。

尚需现场核对区域方向、真实拔插/重启恢复和连续约 10 分钟运行；短时联调不替代这些验收。
新增地面参考与彩色表面的实物轮廓效果尚需现场确认；上述表面截图和窗口检查均为合成数据。

## 本版边界

不包含传感器测距精度标定、滤波、保存回放、物理坐标投影或模型重建。软件不会判断场景是否为空；采集时未移走的物体会成为地面参考，传感器移动后应重新采集。
