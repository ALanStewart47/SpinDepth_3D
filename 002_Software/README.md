# SpinDepth3D 实时查看器

直接读取已完成的 STM32 测距 demo：115200、8N1、8×8、约 5 Hz。一个窗口同时显示距离数字/伪彩色和可旋转的三维区域网格。固件保持原样。

## 本机启动

项目虚拟环境已创建在 `.venv`。当前检测并实测的 CH340 端口是 COM33；更换连接后以设备管理器中的端口为准。在 PowerShell 中执行：

```powershell
Set-Location 'D:\Github\SpinDepth_3D\002_Software'
& '.\.venv\Scripts\python.exe' main.py --port COM33
```

先关闭占用同一 COM 口的串口助手。窗口内拖动鼠标旋转三维视角，滚轮缩放。关闭窗口会停止接收并释放串口；拔线后重新连接设备，再重新启动程序。

当前使用 Tkinter 单窗口和 Open3D 旧版 `Visualizer` 渲染，绕开本机 AMD 驱动上出错的 Filament 路径。Tkinter 随当前 Python 提供，无需新增 pip 依赖；渲染和界面更新都在主线程中进行。

## 新环境安装

使用 Python 3.12 x64。在本目录执行：

```powershell
py -3.12 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements.txt
```

无需激活虚拟环境。当前本机 `.venv` 使用应用附带的 Python 3.12.14 创建；如果该基础运行时迁移或被删除，应使用自己安装的 Python 3.12 重建 `.venv`。

## 数据与显示约定

- 仅发布收齐 D0～D7、S0～S7、N0～N7 的完整帧；每行 8 个值，目标数总和应与帧头一致。拆包、粘包、残帧、异常行和设备重启后均可重新同步。
- 距离已经是毫米，不重复缩放。有效性沿用 `N > 0` 且 `S = 5 或 9`；无效格显示 `--`，不生成三维点。
- 保持固件数组顺序：第 0 行在最上方，第 0 列在最左侧。实物方向对应尚待实机确认，确认后只修改统一映射。
- 色标固定为 0～1000 mm，近处橙色、远处蓝色。范围外的数据仅截断颜色，仍按实际距离显示数字和点位置；灰色表示缺失。
- 三维坐标为 `X = col - 3.5`、`Y = 3.5 - row`、`Z = -distance_mm / 100`。距离越近，点越高；X/Y 是区域索引，Z 每显示单位对应 100 mm。这是区域网格预览，不能用于测量物体长宽或解释为真实三维尺寸。
- 仅使用最新完整帧，不积压显示队列。2 秒未收到完整帧或串口断开时，清空旧画面并提示状态；全无效帧是合法的空点云。
- 帧率按主机接收完整帧的时间估计。FRAME 为会回绕的传感器计数；不宣称采集时间、精确丢帧率或 CRC 校验结果。`Parse errors` 统计被丢弃的解析候选/异常行，不等同于丢失帧数。固件 `ERROR` 信息同时输出到启动终端。

## 检查

无需硬件的自动测试：

```powershell
& '.\.venv\Scripts\python.exe' -m unittest discover -s tests -v
```

窗口冒烟检查无需开发板，使用测试文本帧打开真实窗口，检查旋转、缩放、连续更新、全无效、部分有效、超时、恢复和断线，再自动关闭：

```powershell
& '.\.venv\Scripts\python.exe' tests\smoke_gui.py
```

测试窗口会在约 10 秒后自动关闭；终端出现 `GUI PASS` 表示正常完成，不是闪退。这只是开发检查，不是产品模拟模式，也不表示实机通过。检查通过时，界面中实际显示的三维图像写入忽略提交的 `artifacts/gui_depth_preview.png`。

本轮逻辑测试 11 项通过，依赖检查通过。修复后的真实窗口检查已通过：64 点显示、二维数值、画面读回、鼠标旋转/缩放、连续 30 帧更新、空点云、超时恢复、断线提示和关闭清理。

原 Filament 界面在本地桌面也会发生 `wglMakeCurrent / Windows error 2000`，并在 AMD `atio6axx.dll` 内访问异常；不能归因于远程桌面。本次仅替换显示实现，未修改系统驱动、显示设置或固件，依赖版本不变。

COM33 实机短时联调已通过：完整窗口运行约 10 秒，接收 53 个完整帧，约 5.0 Hz，解析错误为 0；真实点云已显示，关闭窗口后接收线程正常退出并释放串口。测试画面保存在忽略提交的 `artifacts/live_COM33.png`。

尚需现场核对区域方向、真实拔插/重启恢复和连续约 10 分钟运行；短时联调不替代这些验收。
