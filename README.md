# SpinDepth_3D

当前阶段：**VL53L8CH 测距 Demo 已完成**（2026-10-15）。已在 STM32G474 开发板上持续读取并通过串口输出 8×8 距离（mm）、目标状态和目标数量，输出频率为 5 Hz。

本阶段已由用户确认验收完成；后续开发按当前测距结果准确的前提推进，不追加精度验证或标定。

工程、接线、编译下载及数据使用说明见 [VL53L8CH Demo 文档](002_Firmware/VL53L8CH_Demo/README.md)。当前使用 ARM Compiler 5，HEX 已生成。

2026-10-16 新增 1 米近距配置：上位机显示和地面采集仅使用 0～1000 mm 内的有效数据；固件维持 8×8、5 Hz，积分时间从默认 5 ms 调为 40 ms，选择最强回波。新 HEX 编译通过，尚未烧录或实测精度提升；此前测距 Demo 的验收结论仅适用于原配置。

电脑端实时查看器已加入 `002_Software`，读取现有文本帧，显示 8×8 距离与相邻测点连接的彩色表面，支持采集逐区地面参考并预览物体的大致起伏和轮廓。已切换至 Tkinter + Open3D 旧版渲染器，绕开本机 Filament 闪退；逻辑测试和真实窗口检查均通过。相对起伏和表面轮廓仍需现场清空区域后采集确认，区域方向与长期运行验收待完成。安装、启动与当前验证状态见 [上位机说明](002_Software/README.md)。
